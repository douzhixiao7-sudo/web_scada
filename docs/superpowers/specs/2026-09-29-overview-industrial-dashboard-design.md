# 首页总览工业大屏样式设计

## 目标

将首页总览升级为深色科技驾驶舱风格，强化 SCADA 运行态势的视觉感受，同时保留后台长期使用所需的清晰度和可读性。

## 范围

- 仅美化首页总览页面，不调整设备、报警、实时监控等其他页面的业务逻辑。
- 保留现有总览数据结构：运行态势评分、设备/点位、当前报警、采集通道、实时数据覆盖、链路状态。
- 优先修改 `frontend/src/style.css`，仅在必要时为 `frontend/src/App.vue` 增加少量装饰性结构。

## 视觉方向

- 页面背景使用暗色工业底色、径向青蓝光晕、细网格和轻微扫描线。
- 顶部运行态势卡作为主视觉横幅，增加发光边框、角标和层级光效。
- 评分模块做成独立状态面板，使用青色、黄色、红色表达健康、警告和危险。
- 指标卡增加发光状态线、内边框和微弱渐变，让数据卡更像运行大屏模块。
- 图表与链路状态面板强化暗色仪表盘质感，保持文字和状态值易读。

## 非目标

- 不新增接口。
- 不改变 ECharts 数据计算逻辑。
- 不改变登录、菜单、设备、报警等业务流程。
- 不引入新的 UI 库或图片资源。

## 验证

- 使用现有 `npm run build` 验证前端类型检查和构建。
- 如开发服务正在运行，通过浏览器检查首页总览视觉效果和响应式布局。
